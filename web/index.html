1. 什么是永续合约▸

永续合约是一种没有到期日的衍生品合约，可以无限期持有。它通过「资金费率」机制使合约价格锚定现货价格。

简单说：你不需要真的买BTC，只需要猜BTC涨还是跌。猜对了赚差价，猜错了亏差价。

举例
BTC现在60000U，你觉得会涨→开多合约→BTC涨到65000→你赚5000U的差价（不需要真的持有BTC）
2. 什么是杠杆▸

杠杆允许你用较少的保证金控制更大价值的仓位。10x杠杆意味着用100U保证金可以控制1000U的仓位。杠杆放大收益的同时也放大亏损，杠杆越高，离强平越近。

公式
保证金 = 仓位价值 / 杠杆倍数
举例
100 USDT × 10倍杠杆 = 控制1000 USDT仓位
价格涨10% → 你赚100%（10倍放大）
价格跌10% → 你亏100%（爆仓）
3. 多空机制▸

开多（做多）= 看涨，价格上涨时盈利，下跌时亏损。
开空（做空）= 看跌，价格下跌时盈利，上涨时亏损。
永续合约的核心优势就是可以双向交易，不管涨跌都能赚钱（如果猜对方向）。

举例
BTC = 60000U
你认为会涨 → 开多 → 涨到65000 → 赚5000U ✓
你认为会跌 → 开空 → 跌到55000 → 赚5000U ✓
4. 未实现盈亏▸

未实现盈亏是你持仓中的浮动盈亏，只有平仓后才会变成真实的盈亏（已实现盈亏）。它会随着价格波动实时变化，还没平仓之前都不算数。

公式
未实现盈亏 = (当前价 - 开仓价) × 数量 × 方向
方向: 多=1, 空=-1
举例
开多 0.01BTC，开仓价60000，当前价65000
盈亏 = (65000-60000) × 0.01 × 1 = +50U（浮盈）
5. 市价单 vs 限价单▸

市价单：以当前市场最优价格立即成交。优点是保证成交，缺点是可能有滑点（大单会吃掉多档价格）。手续费较高（Taker 0.04%）。

限价单：你指定一个价格，只有市场价到达这个价格才成交。优点是价格更好，手续费更低（Maker 0.02%），缺点是可能不成交。

举例
BTC = 60000
市价买入 → 立即以60010成交（吃卖盘最低价）
限价58000买入 → 挂单等待 → 价格跌到58000才成交
6. 手续费 (Maker/Taker)▸

每次开仓和平仓都要付手续费。Taker=你的单立即和订单簿里的挂单成交（你"吃掉"了别人的单，费率0.04%）。Maker=你的单挂在订单簿里等别人来吃（你"提供"了流动性，费率0.02%）。

市价单一定是Taker；限价单如果价格穿过了对手盘也会立即成交变成Taker，只有挂在订单簿里等待时才是Maker。

公式
手续费 = 仓位价值 × 费率
仓位价值 = 保证金 × 杠杆
举例
100U保证金 × 10x杠杆 = 1000U仓位价值
Taker手续费 = 1000 × 0.04% = 0.4U
开仓+平仓 = 0.8U（别小看，频繁交易很快累积）
7. 止盈止损▸

止盈(TP)：价格到了你设定的目标价，自动平仓锁定利润。
止损(SL)：价格跌到你设定的底线，自动平仓限制亏损。

重要：TP和SL是OCO关系——触发一个会自动取消另一个。建议每笔交易都设止损！

举例
60000开多
设止盈65000 → 涨到65000自动平仓，赚5000
设止损58000 → 跌到58000自动平仓，亏2000
不设止损 → 可能跌到强平价，亏掉全部保证金
8. 资金费率▸

每8小时结算一次（00:00/08:00/16:00 UTC）。用于让合约价格锚定现货价格。

费率为正 → 做多的人付钱给做空的人（做多有成本）
费率为负 → 做空的人付钱给做多的人

公式
资金费 = 仓位价值 × 资金费率 × (-方向)
其中: 多头方向=1, 空头方向=-1

举例: 仓位价值10000U, 费率=+0.01%

多头: 10000 × 0.0001 × (-1) = -1U (负数=付出)
空头: 10000 × 0.0001 × (1)  = +1U (正数=收到)

→ 费率为正时, 多头付1U给空头
为什么需要资金费率？
如果做多的人太多，合约价格会被推高。资金费率让多头付钱，激励更多人做空，从而让合约价格回到现货水平。这就是永续合约"永续"的秘密——不靠到期交割，靠资金费率锚定。
9. 强制平仓（爆仓）▸

当你的保证金率降到0.5%以下时，系统强制平仓，你会亏掉全部保证金。杠杆越高，强平价离开仓价越近，越容易爆仓。

公式
强平价(多) = 开仓价 × (1 - 1/杠杆) / (1 - 0.5%)
保证金率 = (保证金 + 未实现盈亏) / 仓位价值
不同杠杆下的强平距离
60000开多：
1x → 价格跌到≈0才爆（几乎不会）
10x → 跌9.5%就爆
50x → 跌2.5%就爆
100x → 跌0.5%就爆（价格动一下）
10. 保险基金与ADL▸

保险基金：交易所的风险缓冲池。强平时如果还有剩余保证金，归保险基金；如果市场跳空导致穿仓（亏损超过保证金），保险基金承担。

ADL（自动减仓）：保险基金耗尽时启动。系统按盈利排名强制减仓对手方——赚得最多的仓位最先被减仓。这是最后的风控手段。

ADL灯
持仓页显示1-5灯，表示你被ADL的风险：
5灯 = 你是最赚钱的，最先被减仓
1灯 = 安全
11. 标记价格与指数价格▸

最新成交价：合约市场的最新交易价格，用于开仓/平仓/盈亏显示。
指数价格：现货市场的价格，更稳定，不容易被操纵。
标记价格：基于指数价格计算，用于强平判断。

为什么不用最新价算强平？因为有人可能故意在合约市场砸一个极低价（闪崩），如果用这个价算强平，大量用户会被不公平地爆仓。标记价格基于现货，防止这种操纵。

公式
基差 = (合约价 - 现货价) / 现货价
标记价格 = 指数价格 × (1 + EMA(基差))
12. 已实现盈亏▸

平仓后的实际盈亏。需要扣除两笔手续费（开仓+平仓）和累计的资金费用。这才是你真正赚到或亏掉的钱。

公式
净盈亏 = (平仓价 - 开仓价) × 数量 × 方向
       - 开仓手续费 - 平仓手续费
       + 累计资金费
13. 逐仓 vs 全仓▸

逐仓(Isolated)：每个仓位独立锁保证金。爆仓只亏这个仓位的保证金，其他不受影响。适合新手。

全仓(Cross)：所有仓位共享账户余额。好处是不容易爆（余额自动补保证金），坏处是一旦爆了全部余额归零。适合高手。

举例
账户1000U，开两个仓各用100U
逐仓：爆一个仓最多亏100U，剩余900U安全
全仓：一个仓亏损会吃掉余额，极端情况1000U全部归零
14. 订单簿与撮合▸

订单簿是所有挂单的集合。买盘(Bid)=想做多的人，卖盘(Ask)=想做空的人。你下单后进入订单簿，和对手方按价格优先、时间优先的规则匹配成交。

做市商会在买卖两边持续挂单提供流动性，确保你随时能成交。做市商赚的是买卖价差(spread)。

撮合规则
1. 价格优先：出价高的买单优先成交
2. 时间优先：同价格先挂的优先成交
3. 成交价=挂单方(Maker)的价格
